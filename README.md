# EMLV — Exercice pratique et prépa DST

Chapitre 1 : Comprendre les états financiers. Application statique, sans compte étudiant ni transmission des réponses locales.

## Contenu
- 8 compétences ; 56 entraînements (1 exemple accompagné + 3 cas progressifs + 3 cas supplémentaires par compétence).
- 8 cas inédits de validation et un sujet blanc de 90 minutes sur 20 points.
- Lexique contextualisé, formules expliquées, corrections fractionnées et indices graduels.
- Dossiers authentiques Carrefour, Meta et AMD, publications officielles 2025, avec pages complètes, source, unités et périmètres.
- SIG sans retraitements. Ratios limités à la sélection de préparation du DST.

## Utilisation
Le fichier `index.html` et ses dossiers constituent une application autonome, consultable sur GitHub Pages ou depuis un serveur statique. Les données sont incluses dans `assets/content.js` : pas de chargement distant nécessaire pour les exercices. La progression reste dans le navigateur de l'étudiant ; elle ne constitue pas une preuve de remise ni de maîtrise. Le bouton d'export produit une copie JSON des réponses.

Documents de cours et calculatrice autorisés ; intelligence artificielle interdite aux étudiants pour les travaux proposés.

## Google Forms
Les huit validations et le sujet blanc disposent de neuf Google Forms actifs. Les neuf formulaires ont été testés en mode répondant et leurs réponses TEST retrouvées dans le suivi privé le 10 novembre 2026. `teacher/Code.gs` correspond au script exécuté, avec neuf déclencheurs de réception. Voir `teacher/INSTALLATION.md`. Aucun fichier de réponses ni identifiant privé de suivi ne doit être ajouté à ce dépôt public.

Les QCM et calculs sont évalués séparément de l'argumentation. Les formats ambigus restent à relire. Aucune réponse ouverte n'est jugée par correspondance exacte de texte ou mots-clés.

## Sources et limites
Les cas d'entraînement sont fictifs et clairement identifiés. Les documents d'entreprises réelles sont conservés avec leur présentation d'origine ; les transcriptions sélectionnées ne sont pas des états exhaustifs. EBE, EBITDA, marge commerciale et gross profit ne sont pas assimilés. Les publications sources et leurs périmètres sont précisés dans les dossiers.

L'application S0 et l'application S4 sont prévues séparément. Les liens S1 à S3 renvoient aux applications existantes.

## Handoff du 10 novembre 2026

Configuration publique activée et vérifiée sur GitHub Pages.
